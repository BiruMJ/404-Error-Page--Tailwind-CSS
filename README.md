# 404 Error Page - Sunleaf Energy

A custom, professional 404 error page designed for Sunleaf Energy. This project uses Tailwind CSS to create a clean, brand-aligned fallback page that maintains user engagement even when a link is broken.

## Screenshot

![Desktop Screenshot](./Screenshot%20Desktop.png)
![Mobile Screenshot](./Screenshot%20Mobile.png)

## 🚀 Features

- **Thematic Design:** Uses professional, energy-focused messaging ("Oops, We've Lost Some Power!") to stay on-brand.
- **Intuitive Navigation:** Includes a full header and footer navigation menu, ensuring the user can easily find their way back to the homepage or other key sections.
- **Responsive Layout:** Fully adaptive layout that maintains professional alignment across desktop and mobile devices.
- **Tailwind CSS Integration:** Leverages utility-first CSS for efficient styling, consistent layout spacing, and clear typography.
